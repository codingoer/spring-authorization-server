# Spring 官方 Verified GitHub 组织完整清单（学习存档）
> 所有组织均带 GitHub 官方 **Verified（蓝色对勾）** 认证，为 Spring 官方维护

## 一、你已知道的 4 个核心组织
### 1. `spring-projects`（主核心）
- **定位**：Spring 生态**主组织**，所有**活跃、主流、生产级项目**大本营
- **代表项目**：`spring-framework`、`spring-boot`、`spring-security`、`spring-data`、`spring-cloud-stream`、`spring-ai` 等
- **状态**：**持续维护、官方第一优先级**

### 2. `spring-attic`（废弃归档）
- **定位**：**已停止维护（EOL）** 项目的“档案馆”
- **代表项目**：`spring-security-oauth`、`spring-security-oauth2-boot`、旧版 Spring Integration 扩展等
- **状态**：**只读归档，不再更新，新项目严禁使用**

### 3. `spring-guides`（官方教程）
- **定位**：Spring 官方**入门教程、示例、Getting Started 代码库**
- **内容**：`Accessing Data JPA`、`Securing Web Apps`、`OAuth2 Login` 等手把手教程
- **状态**：持续更新，**学习首选官方示例**

### 4. `spring-cloud`（微服务专属）
- **定位**：**Spring Cloud 微服务生态独立组织**
- **代表项目**：`spring-cloud-gateway`、`spring-cloud-netflix`、`spring-cloud-config`、`spring-cloud-openfeign` 等
- **状态**：活跃维护，**微服务开发必备**

---

## 二、其他官方 Verified 组织（补充完整）
### 5. `spring-io`（平台与构建）
- **地址**：https://github.com/spring-io
- **定位**：Spring 平台、构建、版本管理、Initializr 相关
- **核心项目**：
    - `initializr`：Spring Boot 初始化器（start.spring.io 后端）
    - `spring-boot-bom`：依赖管理、版本仲裁
- **状态**：官方核心、活跃维护

### 6. `spring-cloud-alibaba`（阿里官方合作）
- **地址**：https://github.com/spring-cloud-alibaba
- **定位**：Spring 官方 + 阿里巴巴 **联合 Verified 组织**
- **代表项目**：`spring-cloud-alibaba-nacos`、`sentinel`、`seata`、`rocketmq` 等
- **状态**：活跃、国内微服务主流

### 7. `spring-cloud-gcp`（谷歌云集成）
- **地址**：https://github.com/spring-cloud-gcp
- **定位**：Spring 官方 + Google Cloud 认证组织
- **用途**：Spring 应用集成 GCP 服务（Pub/Sub、Storage、SQL 等）

### 8. `spring-cloud-aws`（AWS 云集成）
- **地址**：https://github.com/spring-cloud-aws
- **定位**：Spring 官方 + AWS 认证组织
- **用途**：集成亚马逊云服务（S3、SQS、DynamoDB 等）

### 9. `spring-cloud-azure`（微软 Azure 集成）
- **地址**：https://github.com/spring-cloud-azure
- **定位**：Spring 官方 + Microsoft 认证组织
- **用途**：集成 Azure 云服务

---

## 三、一句话总结（便于记忆）
- **核心 4 个**：`spring-projects`(主)、`spring-attic`(废弃)、`spring-guides`(教程)、`spring-cloud`(微服务)
- **平台 1 个**：`spring-io`(构建/Initializr)
- **云厂商 3 个**：`spring-cloud-alibaba`/`gcp`/`aws`/`azure`（均为官方联合认证）

> **判断规则**：GitHub 主页带 **蓝色 Verified 对勾**、归属 `spring.io` 官方域名、采用 Apache-2.0 协议 → 即为**官方认证组织**。
